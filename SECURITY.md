# Security policy

## Supported versions

Only the `main` branch is supported. Pipelines generated from this template are the responsibility of
their own maintainers.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub's private vulnerability reporting:
<https://github.com/lifebit-ai/lifebit-nextflow-template/security/advisories/new>

Include the affected file or workflow, steps to reproduce, and the impact you believe it has. We will
acknowledge the report and keep you informed while we work on a fix.

Vulnerabilities in Nextflow itself should be reported to Seqera:
<https://github.com/nextflow-io/nextflow/security/policy>
